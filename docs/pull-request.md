# PR: 과학 실험 추천 플랫폼 구현

사용자가 질문에 답하면 조건 일치율 순으로 실험을 추천하고, 피드백으로 항목 배점과 신뢰도를 조정합니다. 직접 실험을 등록해 유사 실험 기반 임시 배점으로 추천에 참여할 수 있습니다. GPT는 서버 전용 API 키로 실험 원리를 설명합니다.

- React·TypeScript + Vite / Express / Node 24 내장 SQLite
- 분기 설문, 가중치 계산 공개, 세션별 중복 피드백 방지, 필수 등록 정보 검증
- 기본 실험 9개, 검색·필터·저장, 데스크톱과 모바일 화면
- `npm ci`, `npm run build`, 로직/API 테스트 15개 및 브라우저 테스트 4개 통과
- GPT 요청·파싱·키 비노출·오류 처리는 모의 응답으로 검증; 실제 키를 사용하는 호출은 아직 미실행

계정·운영자 승인·신고/삭제 기능은 후속 범위입니다. 커뮤니티 실험은 검토 전으로 표시합니다. 일치율과 신뢰도는 안전성이나 성공 확률이 아닙니다.

실행과 배점 설명은 [README](../README.md), 화면은 [데스크톱](screenshots/home.png)·[모바일](screenshots/mobile.png)을 참고하세요.
